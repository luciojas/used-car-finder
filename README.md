# Used Car Finder

An AI-powered used car search app that ranks listings by value, considering more than price. 

## What it does

-You describe what you want in plain English
-Gemini AI parses your search into structured filters
-Pulls live listings from car marketplaces
-Scores each listing by price vs market average, mileage, reliability, and free Carfax history availability

## Built with
-React
-Google Gemini API
-MarketCheck API
-CSS
